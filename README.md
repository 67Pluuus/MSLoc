# MSLoc

MSLoc is a two-stage pipeline for localizing AIGC-tampered segments in long videos.
The inference entry points and their behavior are synchronized with `MSLoc_ori`:

1. **MSLoc-PG** uses a DeMamba backbone with boundary-aware four-class prediction to generate coarse proposals.
2. **MSLoc-PR** uses a TRACE-based MLLM to refine proposal boundaries and generate forensic outputs.
3. The long-video evaluator reports the final paper metrics.

[![Project Page](https://img.shields.io/badge/Project-Page-3273DC)](https://debby-0527.github.io/TASLE/)
[![TASLE Dataset](https://img.shields.io/badge/TASLE%20Dataset-ModelScope-624AFF)](https://www.modelscope.cn/datasets/L67plus/TASLE)

The restored inference code includes the original `loc`, `ref`, `ref2`, and `det` paths. The original implementation behavior is retained as-is.

## Layout

The repository contains code only.  Download TASLE and backbone from [ModelScope](https://www.modelscope.cn/datasets/L67plus/TASLE), then use this sibling-directory layout. The `results/`, `output/` and `inference_results/` directories below are generated by the training and inference steps.

```text
<workspace>/
├── MSLoc/
│   ├── MSLoc-PG/              # proposal generation
│   ├── MSLoc-PR/              # proposal refinement
│   ├── scripts/
│   └── README.md
└── MSLoc_assets/
    ├── data/
    │   └── Tasle-CoT-10K/
    │       ├── annos/
    │       │   ├── train_all_1209.json
    │       │   └── test_all_1209_0119.json
    │       ├── videos/
    │       └── video_frames/
    ├── DeMamba/
    │   ├── pretrained_weights/xclip-base-patch16/
    │   └── results/all_Class_4/  # training outputs
    └── Trace/
        ├── ckpts/trace-uni/
        ├── ckpts/clip-vit-large-patch14-336/
        ├── bge-large-en-v1.5/
        ├── output/trace_vllava/ref2/  # training outputs
        └── inference_results/
```

The code directories follow the paper names `MSLoc-PG` and `MSLoc-PR`. The asset directories retain the `DeMamba` and `Trace` names. The default paths assume `MSLoc_assets/` is beside this repository. MSLoc-PR paths can also be overridden with `MSLOC_ASSETS`, `DATA_ROOT`, `MODEL_DIR`, `TEST_ANNO_FILE`, and `VIDEO_DIR`.

## Environments

MSLoc-PG and MSLoc-PR use separate environments.

### Stage 1: MSLoc-PG

```bash
conda create -n msloc-pg python=3.10 -y
conda activate msloc-pg
pip install -r MSLoc-PG/requirements.txt
```

### Stage 2: MSLoc-PR

MSLoc-PR training and inference require Linux and an NVIDIA GPU. Use PyTorch 2.1.2 with CUDA 12.1 for the existing DeepSpeed 0.13.1 dependencies.

```bash
conda create -n msloc-pr python=3.10 -y
conda activate msloc-pr
python -m pip install setuptools==69.5.1 wheel==0.43.0 numpy==1.26.4 ninja packaging
python -m pip install torch==2.1.2 torchvision==0.16.2 torchaudio==2.1.2 \
    --index-url https://download.pytorch.org/whl/cu121
python -m pip install --no-build-isolation -r MSLoc-PR/requirements.txt \
    torch==2.1.2 torchvision==0.16.2 torchaudio==2.1.2 \
    numpy==1.26.4 huggingface-hub==0.23.4 \
    nvidia-cuda-runtime-cu12==12.1.105 nvidia-cublas-cu12==12.1.3.1 \
    nvidia-cusparse-cu12==12.1.0.106 nvidia-nvjitlink-cu12==12.1.105
```

Locate the pip-installed CUDA libraries and save their search paths for bitsandbytes; Conda applies them on activation.

```bash
MSLOC_NVIDIA_DIR=$(python -c 'import sysconfig; print(sysconfig.get_paths()["purelib"] + "/nvidia")')
MSLOC_CUDA_LIBS="${MSLOC_NVIDIA_DIR}/cuda_runtime/lib:${MSLOC_NVIDIA_DIR}/cublas/lib:${MSLOC_NVIDIA_DIR}/cusparse/lib:${MSLOC_NVIDIA_DIR}/nvjitlink/lib"
conda env config vars set LD_LIBRARY_PATH="${MSLOC_CUDA_LIBS}${LD_LIBRARY_PATH:+:$LD_LIBRARY_PATH}"
conda deactivate
conda activate msloc-pr
python -c "import torch, cv2, bitsandbytes, deepspeed; from transformers import Trainer; assert torch.cuda.is_available(); print(torch.__version__, torch.version.cuda, torch.cuda.get_device_name(0))"
```

## Training

Use the environments and asset layout above, with the Mistral-based `trace-uni` model.

### 1. Prepare data

Extract 8-fps frames (skip if prepared) and reserve 10% of training videos for validation.

```bash
cd MSLoc/MSLoc-PG
conda activate msloc-pg
python Preprocess/video2frame.py \
    --input_root ../../MSLoc_assets/data/Tasle-CoT-10K/videos \
    --output_root ../../MSLoc_assets/data/Tasle-CoT-10K/video_frames
python ../scripts/prepare_train.py \
    --anno_file ../../MSLoc_assets/data/Tasle-CoT-10K/annos/train_all_1209.json \
    --output_dir ../../MSLoc_assets/data/Tasle-CoT-10K/annos \
    --val_ratio 0.1 --seed 42
```

Outputs: `video_frames/` and `annos/msloc_train.json` / `annos/msloc_val.json` under the dataset directory.

### 2. Train MSLoc-PG and generate proposals

In the `msloc-pg` environment:

```bash
cd MSLoc/MSLoc-PG
python train.py \
    --config ./configs/MSLoc_train.yaml \
    --device-ids 0,1,2,3,4,5,6,7 \
    --epochs 10 \
    --lr 1e-6 \
    --batches-per-epoch 1000 \
    --train-batch-size 32 \
    --micro-batch-size 4 \
    --val-batch-size 32 \
    --val-videos 0 \
    --num-workers 4 \
    --seed 42 \
    --clean
python eval.py \
    --config ./configs/XCLIP_Tasle_train.yaml \
    --model_path ../../MSLoc_assets/DeMamba/results/all_Class_4/best_acc.pth \
    --output_dir ../../MSLoc_assets/DeMamba/results/all_Class_4/eval_train \
    --max-videos 0 \
    --batch-size 32 \
    --num-workers 4
```

Outputs: `../../MSLoc_assets/DeMamba/results/all_Class_4/`, including `eval_train/predictions.json`.
Single GPU: `--device-ids 0` (effective batch 32). Resume: `--resume`.

### 3. Train MSLoc-PR

In the `msloc-pr` environment, extract class features and train with DAM, EAM and anomaly-aware loss:

```bash
cd MSLoc/MSLoc-PR
python trace/scripts/extract_class_features.py \
    --data_path ../../MSLoc_assets/data/Tasle-CoT-10K/annos/train_all_1209.json \
    --bge_model_path ../../MSLoc_assets/Trace/bge-large-en-v1.5 \
    --output_path ../../MSLoc_assets/Trace/class_features_bge.pt \
    --device cuda --batch_size 32
python -m torch.distributed.run --standalone --nproc_per_node=8 trace/train_mt.py \
    --global_batch_size 16 \
    --per_device_train_batch_size 2 \
    --per_device_eval_batch_size 1 \
    --train_videos 0 --val_videos 0 \
    --num_train_epochs 2 \
    --max_steps -1 \
    --evaluation_strategy epoch \
    --save_strategy epoch \
    --save_steps 500 \
    --logging_steps 1 \
    --learning_rate 3e-5 \
    --num_frames 40 \
    --model_max_length 4096 \
    --dataloader_num_workers 4 \
    --bf16 True \
    --report_to none \
    --seed 42 --data_seed 42 \
    --clean
```

Outputs: `../../MSLoc_assets/Trace/output/trace_vllava/ref2/`.
Single GPU: `--nproc_per_node=1` (effective batch 16). Resume: `--resume_from_checkpoint latest`.

## Inference

### 1. Extract 8-fps frames

Run once before Stage 1:

```bash
cd MSLoc/MSLoc-PG
python Preprocess/video2frame.py \
    --input_root  ../../MSLoc_assets/data/Tasle-CoT-10K/videos \
    --output_root ../../MSLoc_assets/data/Tasle-CoT-10K/video_frames
```

The extractor resolves both roots before starting workers and reprocesses incomplete frame directories.

### 2. Generate four-class proposals

```bash
cd MSLoc/MSLoc-PG
bash eval.sh
```

The classifier uses 2-second windows with 8 sampled frames. Its classes are `0=real`, `1=fake`, `2=real-to-fake`, and `3=fake-to-real`.

The proposal file is written to:

```text
MSLoc_assets/DeMamba/results/all_Class_4/eval/predictions.json
```

### 3. Run TRACE/MSLoc-PR inference

Use the entry point matching the model and experiment:

```bash
cd MSLoc/MSLoc-PR
bash scripts/eval/loc_eval.sh    # plain end-to-end Trace, full-video input
bash scripts/eval/ref_eval.sh    # ref, proposal-conditioned input
bash scripts/eval/ref2_eval.sh   # ref2/MSLoc-PR, proposal-conditioned input
bash scripts/eval/det_eval.sh    # binary detection path
```

These launchers retain the original `MSLoc_ori` configuration and use eight GPUs.

Multi-GPU chunks are merged automatically. The final prediction file is:

```text
MSLoc_assets/Trace/inference_results/ref2_aigc_test/fmt_aigc_test_f40_result.json
```

An explicit-path example is:

```bash
MSLOC_ASSETS=/abs/path/to/MSLoc_assets \
DATA_ROOT=/abs/path/to/Tasle-CoT-10K \
MODEL_DIR=/abs/path/to/MSLoc_assets/Trace/output/trace_vllava/ref2 \
TEST_ANNO_FILE=/abs/path/to/predictions.json \
VIDEO_DIR=/abs/path/to/Tasle-CoT-10K/videos \
bash scripts/eval/ref2_eval.sh
```

### 4. Compute the paper metrics

```bash
cd MSLoc
python scripts/evaluate_long.py \
    --gt_file    ../MSLoc_assets/data/Tasle-CoT-10K/annos/test_all_1209_0119.json \
    --infer_file ../MSLoc_assets/Trace/inference_results/ref2_aigc_test/fmt_aigc_test_f40_result.json
```

Use `test_all_1209_0119.json` as ground truth for long-video evaluation. It reports:

- `Det_Acc`: video-level detection accuracy.
- `Loc_F1`: temporal-grid F1 at the released 0.01-second resolution.
- `Loc_IoU`: mean segment-matching F1 over IoU thresholds `{0.1, 0.3, 0.5, 0.7}`.

## Inference data flow

| Artifact | Producer | Consumer |
| --- | --- | --- |
| `video_frames/` | `MSLoc-PG/Preprocess/video2frame.py` | `MSLoc-PG/eval.py` |
| `all_Class_4/eval/predictions.json` | `MSLoc-PG/eval.py` | `MSLoc-PR/trace/eval/evaluate_ref.py` |
| `ref2_aigc_test/fmt_aigc_test_f40_result.json` | `MSLoc-PR/scripts/eval/ref2_eval.sh` | `scripts/evaluate_long.py` |

MSLoc-PG testing and final long-video metrics use `MSLoc_assets/data/Tasle-CoT-10K/annos/test_all_1209_0119.json`.
